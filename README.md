# 双语默写练习（MVP）

> 面向中小学生「**看中文 → 写英文**」的英语知识点默写练习工具。单文件 HTML，纯前端、可离线，打开即用。

## 为什么做这个

老师发的英汉双语清单，学生常常"看着眼熟、写不出来、中式翻译出错"。本工具把清单变成可练习的词库，只训练**中文 → 英文**的逆向输出（对标课堂默写考核），并支持掌握度分层、薄弱项复习、浏览器朗读中文提示。

## 功能特性

- 📥 **多种导入**：粘贴 `英文|中文`、上传 `.txt` / `.csv`、或先用工具把 PDF 清单转成 CSV
- 🗂️ **分组管理**：按单元 / 课自动分组，支持单条增删改、重命名、删除、置顶
- ✍️ **默写练习**：看中文写英文，归一化判题（忽略大小写 / 多余空格 / 标点）
- 🏷️ **掌握度分层**：未学 / 熟练 / 模糊 / 不会，自动分流题库
- 🔁 **复习模式**：自动汇聚"模糊 + 不会"及到期回顾的"熟练"词条，优先巩固薄弱项
- 🔊 **语音朗读**：调用浏览器内置 Web Speech API 朗读中文提示 / 英文答案（无需联网、无需后端）
- 💾 **本地存储**：全部数据存 `localStorage`，离线可用，刷新不丢

## 快速开始

直接用浏览器打开根目录的 **`双语默写练习_MVP.html`** 即可。

首次打开已内置一份示例词库（共 **139 条**，来自某教材 U1–U3 语言点汇总，已按单元 / 课分 9 组），可直接选分组开始练习。

## 导入自己的词库

进入「导入」页，支持三种方式：

- **粘贴**：每行一条 `英文 | 中文`（竖线或 Tab 分隔均可）
- **文件**：选择 `.txt`（同格式逐行）或 `.csv`（`en,zh,group` 三列；自动跳过表头、自动纠偏"中文在前/英文在前"的列序）
- 解析后会在文本框预览并提示条数，**确认无误再点「解析并导入」**，避免误导入

### 从 PDF 生成词库（可选）

`tools/parse_pdf.py` 可将带**文字层**的双语 PDF 清单转为 `en,zh,group` 的 CSV：

1. 修改脚本顶部 `PDF` 常量为你的 PDF 路径；
2. 安装依赖：`pip install pymupdf`；
3. 运行：`python tools/parse_pdf.py`，生成 CSV（UTF-8 BOM，Excel 可直接打开）与 JSON。

> 说明：该脚本针对"英文/中文顺序混杂、中英文小标题中英文混用、含换行拆词"的教材类清单做了容错处理；手写体或纯图片 PDF 需先 OCR，不在该脚本范围。

## 技术实现

- **纯前端单文件**：原生 HTML + JS，无构建、无第三方依赖、无后端
- **数据存储**：浏览器 `localStorage`（源码中 `KEY` 常量）
- **语音朗读**：`window.speechSynthesis`，中文 `zh-CN`、英文 `en-US`（语音包取决于系统 / 浏览器，缺失时静默降级）
- **判题逻辑**：归一化（去首尾空格、去标点、转小写）后比较；句型 / 短语也按整串比对
