## 一、产品概述

### 1.1 产品定位

面向中小学生（小学、初中）的英语知识点专项记忆工具，专为**老师给出中文提示、学生默写英文**的课堂考核场景打造。解决学生看双语清单"眼熟"、默写卡壳、中式翻译出错、记忆效率低、无针对性复习的核心痛点，结合科学间隔记忆方法，实现快速、精准、长效的中英知识点记忆。

### 1.2 产品目标

1. 学生从"拿到纸质清单"到"开始记忆"的导入时间 ≤ 3 分钟（拍照 + 核对）；
2. 学习产出聚焦"中文 → 英文"逆向输出能力，与课堂考核模式完全一致；
3. 记忆效果可沉淀：错题分流、间隔复习、掌握程度可视。

### 1.3 核心功能总览

| 模块 | 说明 | 优先级 |
|---|---|---|
| 拍照上传 & 智能识别 | 拍照/相册导入双语清单，OCR 识别并自动配对中英词条 | P0 |
| 智能卡片记忆 | 中文在前、英文隐藏的卡片学习，支持掌握度分层标记 | P0 |
| 全真模拟默写测试 | 中文提示 → 键盘输入英文 → 智能批改 | P0 |
| 科学间隔复习 | 简化艾宾浩斯曲线，自动规划并推送今日复习内容 | P0 |
| 错题本专项 | 错题分类沉淀、专项刷题、导出打印 | P1 |
| 知识点管理 | 分组管理、手动增删改、本地缓存 + 云端备份 | P1 |

### 1.4 术语定义（统一口径）

| 术语 | 定义 |
|---|---|
| 词条 | 一条中英文对照知识点（中文释义 + 英文单词/短语/句型），为最小记忆单元 |
| 中英对照 | 统一使用"中英"表述（弃用"英汉"混用） |
| 完全不会 | 学生完全想不出对应英文（原稿"提取失败"统一为本术语） |
| 拼写失误 | 学生知道答案，仅存在拼写偏差（判定规则见 4.3.2） |
| 中式翻译错误 | 学生写出的英文结构/搭配不符合英文习惯表达 |

## 二、核心用户与核心痛点

### 2.1 核心用户

- **主要用户**：小学、初中学生（约 8–15 岁）；
- **使用场景**：适配老师"中英双语对照知识点清单 + 中文提示写英文"的教学考核模式；
- **次要相关方**：家长（监管学习、接收合规告知）。

### 2.2 用户痛点

1. 对照双语文本背诵时大脑"视觉偷懒"：看得懂、记不住、写不出；
2. 缺乏"中文 → 英文"逆向输出的针对性练习，与课堂考核模式脱节；
3. 知识点杂乱无章：无分组记忆、无错题沉淀，无效重复背诵；
4. 手动整理卡片耗时，纸质/图片版知识点清单难以快速录入。

## 三、核心功能需求

### 3.1 拍照上传 & 智能识别（P0，核心新增）

#### 3.1.1 功能描述

支持拍摄/导入老师下发的中英双语对照清单图片，自动识别、分离并配对中文释义与英文内容，无需手动输入，一键生成记忆题库。

#### 3.1.2 功能点

| 编号 | 功能点 | 说明 |
|---|---|---|
| FR-101 | 拍照/相册双模式 | 支持实时相机拍摄、相册选择图片导入；支持一次导入多张图片并按顺序合并为一个清单 |
| FR-102 | 智能图文识别（OCR） | 精准区分分行、分条的中文释义与英文单词/短语/句型，自动配对绑定；适配竖版/横版文档、密集排版的双语表格 |
| FR-103 | AI 纠错优化 | 自动修正识别错别字、漏字母、乱序问题；识别结果以可编辑列表呈现，支持逐条手动修改、删除、调整中英配对关系 |
| FR-104 | 手动兜底录入 | OCR 失败或识别质量过低时，提供逐条手动输入的兜底流程，不清空已识别内容 |
| FR-105 | 自定义分组导入 | 识别确认后可命名知识点分组（如：六年级 Unit3、期末重点短语），支持选择教材版本标签（待确认项 OI-1） |
| FR-106 | 去冗余净化 | 自动过滤图片水印、手写涂鸦、多余批注，仅保留标准中英知识点；无法判定的内容标记为"待人工确认"而非静默删除 |

#### 3.1.3 识别质量指标（分级）

| 文本类型 | 准确率目标 | 整页识别 + AI 纠错耗时目标 |
|---|---|---|
| 标准打印文本 | ≥ 95% | ≤ 5 秒 |
| 打印为主 + 少量手写标注 | ≥ 90% | ≤ 8 秒 |
| 手写体为主 | ≥ 80%（尽力识别，引导用户核对） | ≤ 15 秒 |

> 说明：原稿"≤2 秒、≥98%"仅对理想打印体且不含 AI 纠错环节成立，对核心的"手写打印混合"场景不具可行性，故调整为分级指标。识别过程中展示进度提示，避免用户感知为卡死。

### 3.2 智能卡片记忆模块（P0）

#### 3.2.1 卡片核心逻辑

所有卡片默认**中文在前、英文隐藏**，完全复刻课堂"给中文写英文"的考核模式。

#### 3.2.2 功能点

| 编号 | 功能点 | 说明 |
|---|---|---|
| FR-201 | 翻看记忆模式 | 仅显示中文，用户回忆完毕后点击显示英文对照校验 |
| FR-202 | 分组轻量化学习 | 系统默认 5–8 条为一组（符合小学生记忆容量），支持自定义每组数量（3–15 条） |
| FR-203 | 分层记忆判定 | 一键标记"熟练掌握 / 模糊记忆 / 完全不会"三类，自动分流题库；支持学习过程中随时修改标记 |
| FR-204 | 学习进度记忆 | 退出后可从上次进度继续，完成一轮自动生成学习记录 |

### 3.3 全真模拟默写测试模块（P0）

#### 3.3.1 功能点

| 编号 | 功能点 | 说明 |
|---|---|---|
| FR-301 | 中文默写测试 | 系统逐条展示中文释义，空白输入框填写对应英文，支持键盘输入（移动端系统键盘） |
| FR-302 | 智能批改 | 按下述判定规则输出结果：正确 / 拼写失误 / 完全错误 / 中式翻译错误（需人工标记项提示） |
| FR-303 | 错题即时收录 | 非正确结果自动归入错题本并按错误类型分类，不混入熟练题库 |
| FR-304 | 测试报告 | 单轮测试结束展示得分、错误分布、建议下一步（重刷错题 / 进入复习计划） |

#### 3.3.2 批改判定规则（明确口径，供开发落地）

1. **预处理**：忽略首尾空格；英文句型统一比较标点（标点缺失不算错，多写标点不算错）；大小写不敏感（专有名词场景除外，系统按词条属性标记）。
2. **拼写失误**：答案与输入的编辑距离（Levenshtein）≤ 2，或仅存在单复数差异（如 word/words）、漏写一个字母、字母相邻调换——判为"拼写失误"。
3. **完全错误**：编辑距离 > 2 且不满足上述宽容规则。
4. **中式翻译错误**：无法纯算法判定，默认归入"完全错误"；批改结果页提供"标记为中式翻译错误"的手动操作，用于错题分类统计。
5. 多答案词条（一个中文对应多个可接受英文）支持配置同义词白名单，命中任一即判正确。

### 3.4 科学间隔复习体系（P0）

| 编号 | 功能点 | 说明 |
|---|---|---|
| FR-401 | 复习计划 | 内置简化版艾宾浩斯记忆曲线，短期节点：当日学完 → 当晚 → 次日 → 第三日 → 第七日 → 第十五日（长期节点为原稿补充，用于对抗长周期遗忘；是否保留见 OI-2） |
| FR-402 | 复习优先级 | 优先复习"模糊、错题"词条，其次旧知识点，最后新知识点 |
| FR-403 | 智能推送 | 首页展示"今日待复习内容"，到期自动置顶，无需手动规划 |
| FR-404 | 复习反馈闭环 | 复习中答错的词条重置复习周期并升级错题等级；连续两次复习正确则降低复习频率 |

### 3.5 错题本专项模块（P1）

| 编号 | 功能点 | 说明 |
|---|---|---|
| FR-501 | 错题分类沉淀 | 三类错题：完全不会（原"提取失败"）、拼写错误、中式翻译错误 |
| FR-502 | 错题专项训练 | 错题单独刷题、单独卡片记忆；已掌握错题可一键清零（移出错题本，回正常题库） |
| FR-503 | 错题导出 | 支持错题清单导出（图片/PDF）与打印，适配纸质默写练习 |

### 3.6 知识点管理功能（P1）

| 编号 | 功能点 | 说明 |
|---|---|---|
| FR-601 | 分组管理 | 分组重命名、删除（删除需二次确认）、置顶、排序 |
| FR-602 | 词条编辑 | 单条词条手动新增、编辑、删除，适配零散知识点补充 |
| FR-603 | 数据存储 | 所有数据本地缓存优先，保证离线可用；云端备份用于防丢失与多设备同步 |
| FR-604 | 同步策略 | 以账号为维度同步；冲突时以"最近修改时间"为准，并在同步页提示被覆盖风险（详见 OI-3） |

## 四、交互体验需求（适配青少年）

1. **极简无广告**：纯学习界面，无弹窗、无信息流、无付费诱导；
2. **低干扰设计**：界面简洁、字体清晰（默认字号偏大、支持调节）、护眼模式，适配长时间背诵；
3. **短时长学习机制**：推荐 10–15 分钟一轮学习，轮次结束自动提醒休息 3–5 分钟（提示可跳过，不强制锁屏，见 OI-4）；
4. **零门槛操作**：拍照即可用，无需复杂设置，学生可独立完成核心流程。

## 五、非功能需求

### 5.1 性能需求

1. 识别质量指标见 3.1.3（分级标准）；
2. 题库加载 ≤ 1 秒、卡片切换 ≤ 200ms、测试批改即时返回（本地判定）；
3. 支持**学习/复习/测试离线使用**（导入后的内容全部本地可用）；**拍照识别与 AI 纠错为在线能力**，离线时提供手动录入兜底（FR-104）——明确离线边界，消除原稿矛盾。

### 5.2 兼容性需求

1. 适配 Android、iOS 双端，适配手机与平板（含横竖屏与折叠屏基础适配）；
2. 最低系统版本：Android 9.0+ / iOS 14+（建议值，评审确认）。

### 5.3 数据安全与合规需求（面向未成年人，必备）

| 编号 | 要求 |
|---|---|
| NFR-501 | 账号体系：支持手机号 + 验证码登录；14 岁以下用户注册须完成监护人同意流程（监护人手机号验证），符合《个人信息保护法》 |
| NFR-502 | 隐私政策：首次启动展示未成年人个人信息处理规则，单独取得同意；提供账号注销与数据删除入口 |
| NFR-503 | 相机/相册权限：按需申请，拒绝授权时提供相册导入替代路径，不阻断使用 |
| NFR-504 | 青少年内容安全：无社交、无 UGC 公开内容、无广告与内购诱导；学习时长提醒（见第四节） |
| NFR-505 | 数据最小化：仅收集账号与学习数据必需字段；上传图片仅用于识别，识别完成后按策略处理（保留原图可选） |
| NFR-506 | 应用上架合规：满足工信部 App 备案、应用商店未成年人保护审核要求 |

### 5.4 可用性与运维

1. OCR 服务异常时明确报错并保留原图供重试；
2. 云端备份失败本地重试队列，不阻塞学习流程；
3. 崩溃率目标 < 0.5%，关键路径埋点（导入成功率、识别耗时、测试完成率）。

## 六、核心产品流程（用户最短使用路径）

```
打开 APP → 拍照导入 → AI 识别分离中英词条 → 用户核对微调（失败可手动录入兜底）
→ 命名分组并确认导入 → 分组卡片记忆（中文回忆英文，标记掌握程度）
→ 模拟默写测试（智能批改）→ 错题自动收录 → 系统安排复习计划 → 循环巩固
```

---

## 七、差异化核心优势

1. 完全对标课堂考核模式，只做"中文 → 英文"逆向输出训练，区别于普通背单词 APP；
2. 纸质清单一键拍照导入，解决手动录入繁琐问题（含识别失败兜底）；
3. 贴合中小学生记忆规律：分组学习 + 短时专注 + 间隔复习，杜绝无效背诵；
4. 精准区分记忆漏洞（完全不会 / 拼写失误 / 中式翻译错误），针对性攻克默写卡壳与中式英语问题。

## 八、待确认问题清单（Open Issues）

| 编号 | 问题 | 建议 |
|---|---|---|
| OI-1 | 是否接入教材版本（人教/外研/译林等）作为分组标签，影响内容组织与后续检索 | 建议一期仅做自由命名分组，教材标签列为二期 |
| OI-2 | 复习节点是否补充第七日/第十五日长周期节点 | 建议保留（已在 FR-401 体现），成本低、对长效记忆价值高 |
| OI-3 | 多设备同步冲突策略是否需要更细的合并规则 | 一期按"最近修改时间优先 + 覆盖提示"即可 |
| OI-4 | 休息提醒是否强制锁屏（防沉迷强度） | 建议仅提醒不强制，避免影响课堂连续使用；如需防沉迷合规再评估 |
| OI-5 | 产品形态：独立 APP 还是微信小程序优先 | 需求按独立 APP 编写；小程序可显著降低安装门槛，建议评审时决策 |
| OI-6 | "英语→中文"反向训练是否纳入范围（当前明确不做） | 维持不做，保持与课堂考核模式一致的差异化定位 |
| OI-7 | 手写体识别准确率 80% 的兜底体验是否可接受 | 建议一期上线前用真实老师清单样本做识别可用性测试 |
